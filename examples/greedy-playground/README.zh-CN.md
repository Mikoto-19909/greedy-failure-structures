# 贪心，会选错吗？

打开本目录的 `index.html` 即可玩，无需安装、联网或启动 Python 服务。文件夹整体复制后仍可离线使用，也可作为静态文件托管。

先点选两个集合，再揭晓答案。三个教学案例分别展示低索引平局带来的失败、首步最大集合带来的失败、以及贪心最优。揭晓后可以逐步回放、查看保留前缀后的最好可能结果，或换一个已选集合尝试修复。

展开编辑区，点击格子改变集合成员，再按“用这个实例挑战”。支持导入导出项目的 `schema_version: 1`、`encoding: "elements"` 单实例 JSON，也可导入具有 `instance` 外层的记录。页面点号从 1 开始显示，JSON 元素编号从 0 开始。导出的是编辑区当前实例。

## 首版范围和验证

目标是让初次访问者在两分钟内玩懂一个反例。仅使用三个精选教学案例和用户手动编辑的小实例，不运行正式研究批次、不推断总体失败率。第一个案例来自 `docs/counterexample_experiments.zh-CN.md`；后两个是为教学构造的例子，不是正式研究抽样数据。

浏览器内按最大新增覆盖、低索引优先实现标准 Greedy，并穷举所有 k 集合组合计算精确最优。最多 8 个集合、12 个元素，允许空集合和重复集合。前缀可达性强制保留已选集合后再求最优，不能用当前 Greedy 覆盖值代替。

实现保持独立，不改变实验引擎、Dashboard 或现有数据。验证包括小实例算法对照、非法导入拒绝、浏览器交互以及窄屏布局。计算模块可由 Node 直接加载；浏览器文件不依赖第三方库。

运行 `node examples/greedy-playground/verify.cjs` 可穷举核对全部 1,536 个三元素、三集合、预算 1–3 的实例，包括各步 Greedy 和强制保留前缀后的最优值，并检查教学案例和非法输入。首次浏览器验收通过点选上限、全部案例、回放/自动播放、重置、编辑、有效及无效导入、导出、390px 窄屏和直接 `file:` 打开；截图保存在本地 `output/playwright/toy-*.png`。

本目录单独复制后游戏仍可用；页尾研究链接需要保留原仓库目录结构。
