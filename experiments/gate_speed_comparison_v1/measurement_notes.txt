Controlled measurement notes

The 21 successful paired command comparisons are in paired_times.csv. raw_times.csv retains all attempts. The old version had two formal fresh-run WinError 5 failures during atomic CSV replacement, plus one failed resume-checkpoint preparation. Entire interrupted pairs were remeasured in alternating order; failed command times and the orphan successful member of an interrupted pair are excluded from paired statistics. These are conditional successful-run timings, not a claim that file-access errors were caused by gates.

An initial old full-workflow attempt was invalidated because the measurement harness set Git author/committer environment variables, which overrode a commit-policy test's deliberately configured identity. That exec session was interrupted and returned exit code 1. Its logs and completed step durations remain under invalid_harness_workflow in raw_times.csv; the interrupted unittest has a log but no completed timing row. They are not used for full-workflow comparisons.

The harness was corrected to use a private Git global config with default human identity, allowing fixture-local Git configuration to override it. Both complete workflows were then run once from NEW clean clones under controlled-workflow/. Both completed all applicable checks and local commits successfully. workflow_steps.csv and workflow_summary.csv contain only these valid complete workflows. The original root repository/worktree was not modified, and no push occurred.

The parent worktree's Git metadata pointer was broken at setup. Fixed revision objects were available from the original local repository; clones used that repository as source without repairing or writing its metadata. Process-local safe.directory entries were needed for cloning across sandbox ownership. Clone preparation and dependency setup are excluded from timings.

All command pairs match stable quick raw/instance data or all three R1 data files. Both workflows also match all three R1 outputs after independent 66-instance verification. Algorithms, model/config, and generator files are unchanged between the fixed revisions. The five R1 task files are identical in both versions.

Only seven serial paired observations per command, and one full workflow per version, were measured on one Windows machine. Shared OS/dependency caches, antivirus/filesystem activity, and order drift remain limitations. Mypy caches were not copied into fresh clones. OR-Tools was unavailable in both versions, producing the documented optional skips. Full-workflow timings include repeatable local execution, checks and commit steps; they exclude task authoring, reasoning, human review, network/CI waits and preparation. The one-time workflow difference is an observation, not a universal percentage guarantee or a measurement of model reasoning speed.
