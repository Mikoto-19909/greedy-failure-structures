## 2. 修订后的研究主线

组间比较没有给出充分证据 → 转向具体决策路径与修复机制 → 在定长模型中定位失效区域并提出局部结构线索 → 用独立新样本确认受控协议差异 → 研究怎样评价单个 Greedy 解的质量，并明确证书的收益与限制。

这是一条便于理解成果的问题主线。写作时须用设计记录核对实际研究动机，不能把事后整理的连贯叙述冒充当时的决策记录。

### Pilot 与 R1/R1c：从组间比较到失效路径

原 pilot 未获得充分的组间失效率差异证据。R1 重分析同一批 60 个实例，定位首次失去最优可达性的步骤，并比较一换一与至多二换二修复。

R1c 必须纳入：3,000 对新样本中，条件平局可避免比例差异估计为 +5.14 个百分点，保守 95% 区间为 [−2.25, 12.52]，方向仍不确定，预定精度目标已达到。不能用 pilot 的显眼现象替代确认结果，也不能把不确定解释成不存在差异。

### R2：定位预算区域并提出结构线索

在定长模型的 1,800 张原图、13,000 条预算记录中探索失效随预算的变化。中间预算较常见失效是有限网格中的经验描述，不是普适相变或单一结构的因果结论。同图跨预算复用，13,000 条记录不是 13,000 个独立样本。

以首选集合的局部交集总量 E0 为线索，提出 R3 可检验问题。机制诊断只覆盖预定的 288 张原图，不能推广为全体原图的机制组成。

### R3：确认特定构造协议的差异

3,000 张独立新原图，每图生成四个端点，共 12,000 个端点。比较保持集合大小及元素频数不变的两种 E0 导向交换协议，首步不可恢复率主差值为 68.15 个百分点，保守 95% 区间为 [63.19, 73.11]。

独立推断单位是原图。首步不可恢复率不等于最终 Greedy 失效率；协议仍改变其他连接性质，不能写成 E0 的单独因果效应或普适预测定律。有限步链也不保证均匀采样或充分混合。

### R4：有效证书、完整比较与认证边界

已完成简单界、前缀界和 L5 DUAL 的数学特化、实现、独立核验及同一固定语料上的比较。13,000 条预算记录中，DUAL 相对前缀界额外收紧 10 条，新增最优认证为 0。

在等长集合及所用的全部 Greedy 前缀条件族下，DUAL 与初始简单界具有相同的最优认证集合。这个带条件的边界与有限实证收益共同支持当前方向收尾。

有效上界 U 确实提供逐实例质量保证 G/U；不得把它夸大成改进的普适最坏情况保证。U>G 只表示当前上界未认证最优，不证明 Greedy 失败。保留既有方法来源，未经文献核查不宣称理论新颖性。

### 阶段之间的承接

- R2 → R3：有报告记录的候选线索与独立确认设计，属于直接承接。
- R3 → R4：从解释失效拓展到认证解的质量；R4 复用 R2 语料，不能写成 R3 已证明机制从而推出 R4。
- R2 与 R4、R4 的两轮比较共享语料，不累加成更多独立样本。

## 3. 确认个人贡献

项目结果与个人贡献分别核对。在第一人称材料落笔前，确认申请者本人在问题选择、实验设计、数学推导、实现和核验中的实际角色，以及协作或 AI 辅助的范围。已有充分上下文时直接采用，缺失时只询问影响措辞的必要信息。

候选贡献维度包括：

- 将宽泛的 Greedy performance 问题转化为可检验问题。
- 设计匹配对照、固定样本与停止规则、保度协议及正确的推断单位。
- 建立独立重放、精确参考和结果核验流程。
- 区分探索与确认，处理不确定结果，并依据理论边界和完整收益决定收尾。

以上是待核对的贡献维度，不自动认定全部由申请者独立完成。第一人称表述应对应实际参与、能够解释并承担判断责任的工作。

## 4. 一页摘要与派生版本

建议英文标题：**Maximum Coverage: Greedy Failure Mechanisms and Instance-Specific Quality Guarantees**。

先以约 450–550 words 为目标，再用实际排版检查一页可读性。Question / Method / Result / Implication 用作每阶段的内部提取提示，最终正文写成简洁自然语言，不必展示四套重复标题。

一页结构：

1. **Research question**：1–2 句，给出项目核心问题。
2. **Why it matters**：1–2 句解释 Greedy、optimality gap 和研究价值。
3. **Experimental progression**：简述 R1/R1c 的转向与不确定结果、R2 的问题来源，重点放在 R3 与 R4。
4. **Key findings**：3–4 条有证据支持的发现，保留不确定结果与有限收益；避免重复上一节所有数字。
5. **Limitations & next question**：约 3 行，说明适用范围和尚未回答的问题。下一问题只是候选，不构成新实验授权。
6. **My contribution**：约 3–4 条，仅使用已确认的个人贡献。

工程设施只在解释可信度时简述，例如 independent replay and validation；独立代理复核不写成外部同行评议。正文链接到精简的证据入口，不展开实现细节。

从该摘要派生：

- **CV**：2–3 bullets，选最强的贡献与结果。
- **PS**：约 100–150 words，解释问题推进如何形成研究兴趣，并在目标项目明确后调整关联。
- **面试**：60–90 秒英文口述，讲清问题、关键设计、主要结果和一次研究判断；无需逐项念完 R1–R4。

优先形成 CV 与面试要点。具体项目、面试形式和个人角色需以用户提供的信息为准；本计划未核验活动安排。

## 5. 执行顺序与完成标准

执行顺序：

1. 提取事实、来源及表述边界。
2. 确认影响第一人称措辞的个人贡献归属。
3. 写成一页英文研究摘要并检查排版。
4. 派生 CV、PS 和面试版本，统一数字、术语及限制条件。

完成时应满足：

- 关键数字、样本单位、指标及区间均能追溯到报告或固定结果。
- R1c 的不确定结果未被省略；R3 协议差异未升级为单变量因果结论；R4 保留有效保证及其认证边界。
- 不把重复预算、构造端点或复用语料当作额外独立样本。
- 摘要约一页，四个版本事实一致，各自适应阅读或口述场景。
- 第一人称贡献有实际依据，方法来源与新颖性措辞准确。
- 验证以来源对照、必要算术检查、排版和口述时长检查为主，不因材料整理重跑正式实验或全套代码测试。

本计划的后续交付是申请材料，不涉及新增研究、代码重构、远端发布或修改既有结果。
