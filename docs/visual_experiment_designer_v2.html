比较哪些算法？

贪心（Greedy）每步选择新增覆盖最多的集合。穷举（Brute force）检查所有候选组合。惰性贪心（Lazy greedy）缓存部分收益计算；这里展示它的选择，不比较耗时。

数据组与教学预览

数据组（Case）是一套数据生成规则。草图用固定案例展示每组的预览；正式实验再接入生成器。

随机种子（Random seed）控制随机数据生成。固定教学案例没有随机抽样；正式方案沿用模板中的种子。
