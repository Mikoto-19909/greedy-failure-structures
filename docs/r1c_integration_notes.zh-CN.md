## 需要保留的测试与工作流

- `8fc1410` 新增 [tests/test_r1c_confirmation.py](../tests/test_r1c_confirmation.py)，
  共 14 个测试方法：10 个输入/完整链路测试、4 个统计语义测试。
  它们覆盖冻结配置与完整配对、运行身份、来源选集覆盖与 exact 状态、虚假最优值、
  低于真实最优值的上界、轨迹/CSV 篡改、失败不发布、已有输出保护、零失败分母、
  零最优值、精确区间端点，以及方向与精度的分离。
- 其中 7 项不需要 SciPy，7 项统计/完整发布链路测试在缺少 SciPy 时明确跳过。
  分层或迁移时应保留这些行为和真正的无效输入，避免只检查说明文字或跳过重要数值测试。
- `8fc1410` 在 [.github/workflows/tests.yml](../.github/workflows/tests.yml) 的必跑
  `unit-tests`（Ubuntu/Python 3.12）中加入 `pip install scipy==1.18.1`，
  让这 14 项在至少一个必要 CI 环境中完整执行。该 SciPy 版本需要 Python >=3.12。
  其他运行矩阵及核心包默认依赖不因此改变。

本次正式结果提交保留上述测试和 CI，另新增
[tests/test_r1c_report.py](../tests/test_r1c_report.py) 中的 2 个路径回归测试：
报告改写到其他目录时，复现参数仍能从仓库根目录打开正确的配置；外部数据路径
保持可执行的绝对路径。它们只依赖标准库，不需要增加 CI 安装步骤。
本次没有再改工作流文件。
新增的报告渲染脚本只从已经独立验证的归档 CSV 生成表格和图；它不承担原始数据验证，
实际图形和数字由正式数据复算及人工/独立复核检查；路径测试验证文件可打开性，
没有增加文档措辞测试。

本轮本地完整 unittest 共 419 项，418 项通过，1 项因缺少可选 OR-Tools 跳过；
mypy 覆盖的 38 个源码文件通过。独立复核重算了全部 6,000 个正式实例及统计，
并实际拒绝篡改的主区间下界；报告路径修复也经过独立复验。
