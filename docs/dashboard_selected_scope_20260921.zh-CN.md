## 本地使用

在本地 main 工作树启动：

```powershell
Set-Location 'D:\test area\greedy-failure\wt-dashboard-mainline'
& '..\wt-fast-verification\.venv\Scripts\python.exe' run_project.py dashboard --port 57862
```

打开 `http://127.0.0.1:57862/workbench`。配置、任务和旁注属于启动工作树的数据目录；其他工作树的本地数据不会自动合并。

- `/experiments`：选择模板，复制为本地配置；基本参数通过表单应用，案例和算法可在完整 JSON 中编辑。预览显示规模、与当前版本/原模板的差异；保存后“到运行中心排队”带入配置但不自动运行。
- `/workbench`：为已有数据设置研究主题、标签和备注，按主题/标签筛选或按主题分组。它们是本地旁注，原始 CSV/JSON 不变。
- `/research` →“提交实验”→ Benchmark：预检配置、填写输出名、workers 和 checkpoint 间隔，再加入队列。三类任务串行；已排队任务保存其配置字节，不受原配置后来编辑影响。
- 运行中心展示已写入 checkpoint 的计数、算法 error/timeout、日志、异常类型及恢复关系。暂停/取消先请求，再等当前计算和 spawn worker 收尾；保留检查点。续跑使用新尝试 ID、同目录与同份冻结配置；已记录的 error 行也不会自动重算。
- Benchmark 完成仅表示计算和报告结束，独立验证显示“未执行”。历史尝试的下载来自当前共享输出目录，非单独历史快照；如果该目录被不同配置覆盖，旧尝试的结果/下载会被拒绝。同配置再次运行可能更新运行时间。
- 正在写入的来源在实验库显示 busy 占位，直接读结果/报告/回放返回冲突；无关数据可浏览。队列开始写入与整个读取区间互斥。暂停/失败等未完成状态不展示可能过期的完整报告，直接旧报告 URL 同样拒绝。
- 专题详情中的“打开曲线、分布、配对与原图”进入 `/research-analysis?source=...`。R2 按单元查看保存曲线与损失分布，并选择两个预算做完整同图配对；R3 保留四端点分母与完整批次主区间；R4/DUAL 比较同记录的界与保存证书。
- 点击图点或记录进入实际集合，查看确定性 Greedy 逐步新增覆盖；可切换预算、R3原图/四端点并导出 JSON，用现有 `replay` 核对。显示一致性与保存见证核对不等同于新求最优值或新做科研独立验证。
