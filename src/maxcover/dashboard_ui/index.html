第一次使用

同样的选择次数，哪种算法覆盖更多？

从候选集合中选出少数几个，让它们覆盖尽可能多的元素。这里可以比较贪心、局部搜索和精确算法的结果。

查看三步操作流程
  1. 选一个小例子入门示例已配好参数，无需编辑文件。
  2. 运行并等待完成先确认运行规模，再点击“运行实验”。
  3. 比较覆盖与差距结果自动选中；先看算法对照，再看图表。

选择示例不会立即运行；查看已有结果也不会重新计算。

GAP SPECTRUM · 差距光谱

贪心在哪里失败

比较本次样本中贪心算法相对最优值的覆盖差距。数值越大，说明这批样本上损失的覆盖越多；不代表所有同类实例。

TABLE · 对照

算法对照

平均覆盖
覆盖的元素数，越多越好。
平均差距
相对已证最优值的覆盖损失，越小越好；0% 表示达到最优，— 表示缺少参考。
平均耗时
同一实例上越短越快，受本机和实例规模影响。

这些数值描述当前样本，不能直接推广到所有实例；入门示例用于熟悉操作。
