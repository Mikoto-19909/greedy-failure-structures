# R4 最终研究成果报告

## 定长最大覆盖中 Greedy 的后验质量保证与上界证书

日期：2026-09-08　项目：greedy-failure-structures

报告范围：初始简单界、整数前缀界与 L5 DUAL 的数学特化、可运行实现、独立验证和完整固定小实例比较。本报告归纳已经完成的 R4 工作，不代表全部 Greedy 失效研究或大实例认证问题已经解决。

### 摘要

本方向研究如何在保持标准 Greedy 选择不变的条件下，用可独立检查的最优值上界 U 给出逐实例质量保证 G/U。研究建立了从初始简单界、Greedy 前缀界到 L5 DUAL 的整数证书方法及验证链，并在同一批 1,800 张原图、13,000 条预算记录上完成配对校准。

结果表明，前缀界相对简单界仅收紧 1 条记录；DUAL 相对简单界收紧 11 条，相对前缀界额外收紧 10 条，全部收紧 1 个覆盖元素。额外收益来自 10 张不同原图，均位于 9,400 条中间预算记录中。DUAL 相比前缀界的中间预算平均 G/U 改善为 0.006416 个百分点，单条最大改善为 7.576 个百分点。收益存在，但在完整旧语料中发生较少。

三种界均认证 10,355 条记录，认证集合逐行相同；另有 543 条真实最优但未获认证。该现象符合已证明的结构限制：对等长集合和包含空集的全部 Greedy 前缀条件族，DUAL 与初始简单界具有相同的最优认证集合。因此，增加这类前缀处理不能解决这一认证缺口。

本方向的最终成果是：一个有明确适用范围的后验认证方法体系、一套能拒绝错误最大化结果和损坏状态的独立验证工具，以及对完整固定语料的收益与成本判断。DUAL 正式四阶段完整墙钟为 76.951 秒，追加独立数字审计为 174.251 秒，合计 251.202 秒。当前规模的执行成本可承担，但现有收益频率及应用依据不足以单独支持大实例研究；本轮在完整小实例比较后收尾。

## 1. 研究问题与评价含义

最大覆盖问题给定 M 个候选集合 S_i 和预算 k，选择 k 个不同索引，使并集元素数最大。记 V 为全部候选索引，f(A) 为索引集合 A 的覆盖值；P_t 为低索引平局裁决的标准 Greedy 在第 t 步后的有序选择前缀。

```text
f(A) = | union_{i in A} S_i |
G = f(P_k)
O = max_{|A| <= k} f(A)
B = f(V)
```

本报告限定无权、单调覆盖，且 1 <= k <= M。允许空集合和重复集合；由于可以补选不同索引，至多选 k 个和恰好选 k 个的最优覆盖值相同。k=0 按公共接口拒绝。

本方向回答两个问题：第一，在当前模型中，哪些后验条件能够改善上界或认证 Greedy 最优；第二，DUAL 相对已有界的额外收紧与完整构造、验证成本是否形成可用的质量保证收益。

| 量或条件 | 含义 | 解释要求 |
| --- | --- | --- |
| G/O | Greedy 的实际近似比 | 需要已证明的精确 O |
| G/U | 经验证的近似比下界 | U 必须是全局最优值的有效上界 |
| U/O | 上界相对精确最优值的松弛程度 | O>0 时至少为 1 |
| U=G | Greedy 最优认证 | 由 G<=O<=U 得到 G=O |
| U>G | 当前上界未认证最优 | 单凭这一条件不能断言 Greedy 失效 |

当 U>0 时，G/U <= G/O，因而 1-G/U 是相对最优性差距的上界。零分母比例记为不适用并保留计数；正式语料没有零分母，零值功能案例另行验证。即使 U=O，只要 G<O，该记录仍是 Greedy 失效实例。

## 2. 方法体系与理论成果

### 2.1 初始简单界与整数前缀界

令 Delta_t 为条件在 P_t 后的最大单集合新增覆盖，已选索引的残余为零。两个基线为：

```text
Delta_t = max_i [ f(P_t union {i}) - f(P_t) ]
U_initial = min(B, k * Delta_0)
U_prefix = min(B, min_{t=0,...,k}[ f(P_t) + k * Delta_t ])
```

任一最优选择至多包含 k 个集合，它们对 P_t 的新增覆盖不超过单集合边际之和，因此每个条件项都是全局 O 的上界。这里必须使用完整 k。条件前缀用于计算上界，并不要求全局最优解保留已经选过的集合。

该前缀界是本项目的简单整数基线；它不被称为文献 L6 的完整 GreeDual1 或 GreeDual2，也不引入一般 LP 对偶求解。[2]

### 2.2 L5 DUAL 的整数覆盖特化

DUAL 采用 Balkanski、Qian、Singer 的 Method 4，以 Method 3 为子程序。[1] 本项目明确选择全部 Greedy 前缀 P_0,...,P_k 作为条件族，包含空集与终点。这一具体条件族、覆盖整数表达与实现细节由项目设计固定。[3]

对条件索引集合 C，先从每个原始候选中删去 C 已覆盖的元素，得到残余 R_i。保留全部 M 个原始索引，按残余大小降序、原索引升序排列；记 s_i 为排序后的单集合大小，F_i 为该顺序下的累计并集大小。

```text
q_0 = 0
q_j = max_{1<=i<=M} min(F_i, q_{j-1} + s_i), j=1,...,k
Q(C,k) = q_k
U_DUAL = min(B, min_{t=0,...,k}[ f(P_t) + Q(P_t,k) ])
```

生产器利用 F_i 非降、s_i 非升的性质扫描阈值交点；独立验证器逐轮遍历全部索引计算最大值。计算和检查均使用整数。证书排序只决定残余计算顺序，原图索引、Greedy 顺序、输入身份及公共 CSV 保持原有契约。

### 2.3 有效性、支配关系与认证边界

**命题一：Method 3 给出有效残余上界。** 假设任意至多 j-1 个残余集合的覆盖不超过 q_{j-1}。对任意非空、至多 j 个集合的选择，取其中排序位置最大的 i：总覆盖不超过 F_i；删去该集合后，剩余覆盖不超过 q_{j-1}，加回它至多增加 s_i，故原总覆盖也不超过 q_{j-1}+s_i。因此总覆盖不超过二者最小值，更不超过遍历所有 i 的最大值 q_j。空选择显然满足上界，从 q_0=0 归纳即可得到 Q(C,k) 的有效性。

对全局最优选择 A*，单调性进一步给出 O <= f(C)+h_C(A*) <= f(C)+Q(C,k)，其中 h_C 是条件残余覆盖函数。证明和证书核验本身不依赖已知 O；精确参考用于此次小实例校准。

**命题二：DUAL 不弱于相同前缀族的整数基线。** 每轮增加量不超过最大残余单集合值，且累计值不超过残余总并集，所以 Q(C,k) <= min(F_M,k*s_1)。对 C=P_t 有 s_1=Delta_t，从而：

```text
G <= O <= U_DUAL <= U_prefix <= U_initial <= B
```

**命题三：非空 Greedy 前缀存在最优认证障碍。** 若 B>G，至少有一个候选 a 覆盖 Greedy 最终并集之外的元素。对于 1<=t<=k，取 T=(P_k\P_t) union {a}，则 |T|<=k，且 T 的残余覆盖严格大于 G-f(P_t)。因此，任一有效的完整 k 残余上界都满足 f(P_t)+Q(P_t,k)>G。非空前缀无法将上界降至 G。

由命题三，旧前缀界的认证等价性适用于一般无权覆盖：U_prefix=G 当且仅当 U_initial=G。对于全部集合等长、大小为 d 的情形，空条件递推又退化为 q_j=min(B,j*d)，故 U_DUAL=G 当且仅当 U_initial=G。

这些结论约束的是最优认证集合，并不说明三个上界的数值总是相同。命题及反例作为本项目的方法特化和推导经过独立代理复核；本报告不主张其文献新颖性，也不将代理一致性等同于外部同行评议。

### 2.4 三个说明边界的已核验案例

| 案例 | 关键数值 | 得到的认识 |
| --- | --- | --- |
| 等长四集合，k=2 | G=O=6；简单界=前缀界=8；DUAL=7 | 可严格收紧，但未新增最优认证 |
| 不等长集合 {0,1},{2},{3}，k=2 | G=O=3；简单界=前缀界=4；DUAL=3 | 等长认证限制不能外推到不等长模型 |
| 两个不相交二元素集合，k=2 | O=4；正确 q=(0,2,4) | 可行但非最大划分 (2,0) 不能证明 U=2 |

第一例的原始集合为 {0,1,2,3}、{0,1,4,5}、{0,1,2,6}、{0,1,2,7}。条件在 P_1={0} 时，s=(2,1,1,0)，F=(2,3,4,4)，q=(0,2,3)，条件界为 4+3=7。

另一个已核验反例使用 {1,2,3}、{1,2,4}、{3,5,6}，k=2。Greedy 覆盖 5，精确 O=6；误用 k-t 会给出伪上界 5。它说明错误预算会破坏有效性，不能通过把结果截断到 G 或接受一条可行见证来修补。[3]

这些都是独立人工构造和功能案例，不计入正式样本，也不用于估计收益频率。

## 3. 数据、设计与证据链

### 3.1 同一固定语料上的两阶段比较

F4 基线校准和 DUAL 比较均使用同一批 R2 原图：N=M 取 12、16、20，集合大小 d 取 2、3、4，每个 (N,d) 单元 200 张图，共 1,800 图。候选集合按定长模型生成，允许重复；跨预算使用同一原图，按原始身份配对。

预算固定为下列去重集合，形成 13,000 条预算记录和 65 个 (N,d,k) 单元，每个单元恰好 200 张图：

```text
budgets(N,d) = unique_sorted(
  {1,N} union { min(N,ceil(lambda*N/d)) }
)
lambda in {1/4,1/2,3/4,1,3/2,2}
```

k=1、k=M 各 1,800 条，其余 9,400 条为中间预算。两份研究报告不能相加为 3,600 图或 26,000 条独立样本。预检使用与正式 exploration 种子域分离的 18 图、130 条预算，未并入正式比较。

方法、原图范围、全部前缀条件、指标、缺失处理、资源约束和停止规则先于正式 DUAL 生产固定。没有筛选未认证记录、删除困难样本、追加样本或依据结果更换方法。[4]

### 3.2 独立核验与精确参考复用

F4 阶段独立枚举精确 O 及字典序最小的恰好 k 个索引见证。DUAL 阶段复用已发布且独立验证的参考，直接从固定 Git 提交对象读取输入、参考和旧证书。它重新检查种子对应的有序集合、实例身份、参考状态、见证索引及覆盖值、旧界算术、新证书和派生结果；没有重新穷举正式 O。

新验证器不导入生产器的关键上界计算。它独立重建 Greedy、每个残余、排序、累计并集和每轮最大值，拒绝错误预算、非最大结果、漏前缀、错误来源、零值处理错误、损坏数据及伪造完成状态。汇总入口也先检查当前记录，避免历史 passed 掩盖之后的数据变化。

全量验收覆盖 1,800 图、13,000 预算和 97,200 个条件问题；逐行表与 65 个单元汇总均核对完成，缺失、重复、界顺序及认证集合异常均为零。另一次独立程序以精确 Fraction 比例核对全部行和单元统计；本次综合报告再次对两阶段保存结果作配对算术核对，未重跑证书或求解器。[5]

### 5.2 预检、内存和存储

DUAL 独立预检覆盖 18 图、130 条预算。所有预检尝试的入口实测合计为 16.131 秒；用于预测的 4.870697 秒是由首次完整调用和已保存阶段计时恢复的保守流程上界，包含最初错误 Git 路径导致的末尾开销。失败及恢复记录保留，输入和证书未因恢复被替换。

对独立合成 1,800 文件目录的扫描开销、固定来源负载和完整输出大小另作检查。正式运行前的保守预测为 1,576.156 秒、512 MiB 内存、65.68 MB 输出，符合单 worker、3,600 秒累计入口时间、6 GiB Python 内存及 2 GiB 输出的本批限制。

正式输出实际为 38,815,583 字节，即 37.02 MiB；四阶段 Python 进程峰值最大为 67.01 MiB，进程树工作集观测最大为 71.16 MiB。外部采样包含启动器、Python、Git，排除监控器，间隔 0.1 秒；三次短进程在打开句柄前已退出。采样可遗漏短进程和尖峰，共享页可能重复计数；追加数字审计未测内存，以上数值不是整个任务的严格内存上界。

## 6. 研究判断、限制与方向结论

本方向得到三个相互支持的成果。首先，有效上界的数学定义已经落实为整数计算和独立最大值检查，质量保证不依赖信任生产器。其次，认证边界说明了当前等长模型中非空前缀为什么不能补回真实最优但未认证的记录。最后，完整配对比较量化了能够取得的额外紧度收益及实际成本，而没有用少量有利案例替代完整结果。

从经验结果看，初始简单界已经承担当前语料中几乎全部最优认证和大部分质量保证作用。前缀项及 DUAL 能改善少量实例，但中间预算平均收益很小。从工程结果看，核心构造和检查可承担，完整成本主要还包含来源关联、证书存储与读取、再次复核及报告审计。这些结论共同支持在当前范围收尾并保留工具。

实证结论的适用范围是无权定长覆盖、指定 Greedy 规则、全部前缀条件族和当前固定小实例语料。DUAL 与初始界认证集合相同这一等长结论，不能推广到不等长集合、不同条件族或所有 DUAL 变体；旧前缀界的认证等价性仍适用于本报告的一般无权模型。经验收益频率不能推广到其他规模、分布或实际业务数据，现有工具和预算上限也不构成大实例性能保证。

本研究没有将新增最优认证设为成功条件，没有新样本确认、总体显著性或因果推断，没有完整实现 L6、通用 LP 或新选解算法。若未来有新的应用问题，应先给出所需质量保证、可接受完整成本、适用模型及独立设计，再决定新的方法或规模；本报告不自动启动这些工作。

**最终结论：R4 当前小实例方向已完成理论特化、可运行实现、独立核验和完整比较。DUAL 的额外收紧有效而稀少，认证缺口受当前模型与条件族限制；现有证据支持本轮收尾，不足以单独支持继续扩大实例规模。**
