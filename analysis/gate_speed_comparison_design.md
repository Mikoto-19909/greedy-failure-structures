# 删除门禁后的速度对比设计

对照版本为 PR #46 前的 `891c389` 与合并后的 `285c3b0`。两份独立本地副本使用
同一 Python、依赖、机器、配置和本轮 R1 工具文件。研究算法及输入生成器须先核对
两个版本一致。源码副本准备和依赖安装不计入命令时间。

比较两类耗时：

1. **实验命令**：相同的 quick 新运行、完整 checkpoint 的 resume，以及本轮 R1
   全部 60 个 pilot 加 6 个功能样例的离线分析（不绘图）。每种先预热两个版本，
   再做 7 对串行测量，交替先后顺序，报告全部时间、配对差和中位数。核对稳定实验
   结果及 R1 数据文件一致，运行时间和旧 manifest 等已退役产物不作内容相等要求。
2. **可重复的新研究任务流程**：把同一组 R1 工具、设计及测试文件加入各自副本，
   暂存、运行 R1、独立重算、执行该版本 CONTRIBUTING 的全部本地检查并本地提交。
   旧版包含许可清单生成/检查、内容检查和提交检查，新版按现行流程处理。每步记录
   耗时和实际退出状态；失败不能算作“更快完成”。完整流程各做一次，按测量局限
   解读，不据此声称精确、普适的百分比收益。

这些测量针对同一研究工作负载及可自动重复的交付步骤。另记录本次任务的实际
端到端耗时，但之前任务的范围、模型等待和人工交互不同，不能将不同任务的总时长
差异直接归因于删除门禁。本比较不测量或宣称模型推理速度发生改变。

数值产物放在 `results/gate_speed_comparison/`；只保存必要的原始时间和汇总结果，
不恢复常设 manifest、文件摘要或文档门禁。性能测量串行执行，避免同时运行其他
本地测试或数值分析。
